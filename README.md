# Teador-Robot
# 🤖 EMO Interactive Robot Companion

Интерактивный робот-компаньон с эмоциональным графическим интерфейсом на базе Arduino, OLED-дисплея SSD1306 и ультразвукового датчика расстояния. 

Проект реализует адаптивное поведение: глаза робота оживают, реагируют на приближение руки, прищуриваются, дрожат от испуга и засыпают при отсутствии активности.

## 🛠 Технологии и Стек
* **Язык:** C++ (Arduino Framework)
* **Дисплей:** OLED 128x64 SSD1306 (Шина I2C)
* **Датчик:** Ультразвуковой дальномер HC-SR04
* **Библиотеки:** `Adafruit_SSD1306`, `Adafruit_GFX`, `NewPing`

## ✨ Ключевые Фичи
* **Процедурная 2D-анимация:** Все эмоции отрисовываются математически через геометрические примитивы, что экономит память МК.
* **Интерактивные эмоции:**
  * **Любопытство (8–20 см):** Плавное вытягивание глаз к объекту.
  * **Испуг (< 8 см):** Микро-тремор (дрожание) глаз и расширенные зрачки.
  * **Радость (20–35 см):** Кинематографичный прищур.
  * **Злость:** Сведение бровей при частых раздражениях.
* **Энергосбережение (Sleep Mode):** Автоматический уход в сон через 10 секунд бездействия с анимацией вылетающих букв `Zzz`.
* **Неблокирующая логика:** Использование таймеров `millis()` для непрерывной обработки анимаций.

## 🔌 Подключение (Pinout)

| Компонент | Пин Arduino |
| :--- | :--- |
| **OLED SDA** | A4 |
| **OLED SCL** | A5 |
| **HC-SR04 Trigger** | D9 |
| **HC-SR04 Echo** | D8 |

## 🚀 Как запустить

1. Клонируйте репозиторий или скопируйте файл `.ino`.
2. Установите библиотеки `Adafruit SSD1306` и `NewPing` через Manger библиотек Arduino IDE.
3. Или запустите готовый проект онлайн в симуляторе [Wokwi](https://wokwi.com).
